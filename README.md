# Домашнее задание №9 (Массивы и методы)

## 📌 Описание проекта
Это домашнее задание выполнено в рамках курса Frontend-разработки.  
Основная цель — отработать навыки работы с массивами, функциями и модулями в JavaScript.

## 🛠 Технологии
- HTML5
- CSS3
- JavaScript (ES6+)

## 📁 Структура проекта
├── index.html # Главная страница (подключает JS-модули)
├── homework-9.js # Основной файл со всеми заданиями
├── comments.js # Модуль с тестовыми данными (комментарии)
└── README.md # Описание проекта


## 📋 Список заданий
| № | Описание |
|---|----------|
| 1-2 | Подключение JS-файла с `type="module"` и фильтрация массива чисел |
| 3 | Проверка наличия элемента в массиве (includes) |
| 4 | Функция для переворота массива (reverse) |
| 5-6 | Экспорт и импорт данных (модули) |
| 7 | Фильтрация комментариев по домену email (.com) |
| 8 | Изменение поля `postId` по условию (id <= 5) |
| 9 | Создание объектов только с полями `id` и `name` |
| 10 | Добавление флага `isInvalid` по длине текста (body > 180) |
| 11 | Получение массива email-ов через `reduce` и `map` |
| 12 | Преобразование массива в строку (toString, join) |

## 🚀 Как запустить
1. Убедитесь, что все файлы лежат в одной папке.
2. Откройте `index.html` в браузере (рекомендуется использовать Live Server в VS Code).
3. Откройте консоль DevTools (F12 → Console), чтобы увидеть результаты выполнения всех заданий.
