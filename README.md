# Homework 12 — ES Modules, Inheritance, Modal & Form

Домашнее задание №12: модульная архитектура JavaScript, 
наследование классов, работа с модальным окном и формой через классы.

## Задачи

1. Пройти тест (результат прикреплён в PR)
2. Реализовать ES-модули: `main.js` — единственная точка входа
3. Реализовать наследование классов
4. Создать класс `Modal` для управления модальным окном
5. Создать класс `Form` для управления формой
6. Проработать контекст функций (`this`)

## Структура проекта

homework-12/
├── index.html      # Разметка страницы (подключает только main.js)
├── main.js         # Точка входа, импортирует остальные модули
├── Modal.js        # Класс Modal
├── Form.js         # Класс Form
├── Cars.js         # Классы Vehicle / Car / Motorcycle (наследование)

## Технологии

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6+): ES-модули, классы, наследование, стрелочные функции

## Как запустить

1. Клонировать репозиторий
2. Открыть `homework-12/index.html` через Live Server (VS Code)
3. Открыть DevTools → Console для просмотра логов

> ⚠️ Важно: проект использует ES-модули, поэтому **нельзя открывать через двойной клик** — 
> нужен локальный сервер (Live Server / `npx serve`).

## Что реализовано

### 1. ES-модули
- `main.js` — единственный скрипт, подключённый в `index.html` (`type="module"`)
- Остальные модули подключаются через `import`

### 2. Наследование классов
- Базовый класс `Vehicle`
- Дочерние: `Car`, `Motorcycle` — используют `extends` и `super`

### 3. Класс `Modal`
- Конструктор принимает `id` модалки
- Методы: `open()`, `close()`, `isOpen()`, `initCloseListener()`
- Слушатель крестика навешивается в конструкторе

### 4. Класс `Form`
- Конструктор принимает `id` формы
- Методы: `getValues()`, `isValid()`, `reset()`

### 5. Контекст функций
- В `addEventListener` используются стрелочные функции для сохранения `this`
